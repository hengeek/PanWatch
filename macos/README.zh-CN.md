# PanWatch macOS 盯盘

独立的 macOS 窗口，读取已有 PanWatch 服务中的持仓、关注股票与行情。点击 Dock 图标唤起窗口，关闭窗口后应用继续运行，再次点击 Dock 可恢复；按 ⌘Q 完全退出。

## 使用

1. 保持 PanWatch 服务运行，本机默认地址为 `http://127.0.0.1:8000`。
2. 双击 `macos/build/PanWatch.app`，填写服务地址与现有账号密码。远程服务使用 HTTPS；本机支持 HTTP。未创建账号时先在 PanWatch 网页中创建。
3. 可将应用复制到“应用程序”，并在 Dock 图标菜单选择“选项 → 在程序坞中保留”。
4. 左侧按账户、市场或自定义关注组筛选股票；选中股票可查看真实日线、账户明细并编辑共享分组。支持搜索名称或代码及暂停自动刷新。

只保存服务地址，密码不保存，登录令牌仅保留在内存中；退出应用后需要重新登录。股票增删、持仓编辑与账户维护仍在 PanWatch 网页中完成。自定义关注分组及股票成员关系保存到 PanWatch 服务，网页端可通过共享 API 读取和修改。暂未接入券商同步。

市值及盈亏统一为人民币；现价、成本保留股票原币。缺少现价或汇率时不计算不完整的总额；休市或过期行情不显示当日涨幅与当日盈亏。断线时保留上次数据并明确提示。没有分时图，不生成模拟走势。

## 构建与验证

在 macOS 安装 Xcode Command Line Tools 后，在项目根目录运行：

```sh
./macos/build.sh
open macos/build/PanWatch.app
```

使用系统 AppKit / WebKit，无需 Electron 或额外运行时。构建产物位于 `macos/build/PanWatch.app`，针对当前 Mac 架构编译，最低 macOS 12。应用使用本地临时签名，尚未做 Developer ID 签名、公证或跨机器分发包。

当前桌面页面由 React / TypeScript 构建并打包在应用内。自定义分组需要更新后的 PanWatch 服务；修改后请重启服务以执行数据库迁移。真实业务数据仍需运行中的 PanWatch 服务及现有账号。

## 地址错误排查

本机 PanWatch 默认使用 `http://127.0.0.1:8000`。如果填写其他应用占用的端口（例如本机 `8080` 的 LingOps 页面），接口可能返回 HTML，无法用于登录。应用会在提交账号密码前检查 `/api/auth/status`，明确提示端口不匹配；不会自动切换到另一服务。

应用会在发送账号凭证前检查 `/api/auth/status`。本地开发版本采用临时签名；跨机器正式发布仍需 Developer ID 签名与公证。
