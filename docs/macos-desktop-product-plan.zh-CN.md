# PanWatch macOS 桌面端功能设计

状态：产品功能设计和实现对照。核心桌面盯盘能力已进入交付验收；当前范围、限制和未完成项见 [具体实施方案](macos-desktop-implementation-plan.zh-CN.md) 第 13 节。

整体架构、界面结构和 DMG 交付设计见 [macOS 整体设计](macos-desktop-overall-design.zh-CN.md)，后续实施以整体设计中收敛的数据口径与阶段安排为准。


## 产品目标

将桌面端升级为日常工作时随手查看的盯盘工作台：看持仓变化、定位需要关注的股票、查看已有分析、设置提醒，深入研究时进入网页版继续处理。

核心路径：唤起窗口 → 看到需要关注的变化 → 选择股票 → 查看依据 → 设置提醒或进入网页处理 → 结果回到通知中心。

## 使用入口

- Dock 主窗口：保留完整股票表格、分组、详情和通知入口。
- macOS 菜单栏小窗：显示用户选定的账户盈亏或置顶股票，点击打开简版列表；数值可隐藏。
- 全局快捷键：用户可配置，唤起或收起盯盘窗口，避免占用系统已有快捷键。
- 迷你模式：仅显示选定分组的名称、现价、涨跌幅，支持置顶、隐藏金额和紧凑行高。
- 点击关闭仅关闭窗口；应用仍可在后台接收事件。明确区分关闭窗口、后台运行、完全退出。

## 主窗口布局

顶部：账户范围、总市值、浮动盈亏、当日盈亏、市场状态、更新时间、隐私开关。
左侧：全部持仓、持仓账户、自定义关注分组、智能筛选、置顶股票。
中间：股票表格，支持自定义列、排序、搜索、拖动顺序。
右侧：点击股票展开详情，保留当前列表位置。
底部：最近提醒、服务连接状态、行情更新时间，避免刷新问题被隐藏。

窄窗口时详情替换列表，可返回；迷你模式单独保存显示偏好。首版不把通知、策略、研究入口全部平铺在同一屏。

## 功能设计

### 1. 持仓与关注分组（第一优先级）

持仓按现有账户组织；同一股票出现在不同账户时，默认保留独立行，提供“按股票合并”视图。合并后展示总股数、加权成本和可展开账户明细。

关注股票支持自定义分组，例如“待买”“长线观察”“港股”“价值投资”。一只股票可加入多个关注分组；分组支持改名、排序、移动和取消成员关系。删除分组时保留股票及持仓。

增加置顶和快速筛选：仅持仓、今日上涨、今日下跌、今日提醒命中、未设置提醒、行情异常。筛选须标明统计范围和日期；行情异常与有效行情分开排序。

网页版已有账户和关注列表。跨端自定义分组、多组归属及分组排序需新增共享存储和接口，不能仅保存在当前 Mac。

### 2. 盯盘表格（第一优先级）

默认列：股票名称及代码、现价、涨跌幅、浮动盈亏、当日盈亏、仓位占比、提醒状态。
可选列：股数、成本、人民币市值、交易风格、最近分析时间、小走势。

支持按涨跌幅、盈亏、市值、仓位排序；固定股票名称列；排序期间不在用户操作时频繁跳行。当前行刷新时轻微标记变动，避免整表闪烁。

成本和现价标明原币，汇总默认人民币；账户范围变更时总览同步变化。关注列表总览显示上涨/下跌/行情缺失数量，不显示没有意义的持仓盈亏。

优先展示已有真实日线小走势，标注“近20个交易日”；分时图单独开发分钟级数据接入、交易时段和缓存。现有 K 线摘要不能直接当作分时数据使用。

### 3. 股票详情抽屉（第一优先级）

点击股票后展示：

- 行情：现价、涨跌幅、币种、所属市场、报价时间、市场状态；数据源有对应字段时展示高低价及成交量。
- 持仓：每个账户的股数、成本、仓位、浮动盈亏和当日盈亏。
- 提醒：生效规则、目标值、最近一次命中，可新增、编辑、暂停。
- 分析：最近一次已完成的分析摘要、生成时间、关联报告，可在网页打开原文。
- 快捷动作：加入/移出关注分组、置顶、复制代码、设置提醒、在网页查看。

基本行情不等待 AI 或新闻返回；分析和新闻独立加载，缺失时明确显示暂无结果。

### 4. 价格提醒与原生通知（第二优先级）

复用网页版的提醒规则、触发记录、冷却时间和每日触发上限；桌面只新增快速设置入口及 macOS 通知展示。

常用入口：价格达到指定值、价格跌破指定值。复杂组合条件沿用网页已有表单，未实现桌面编辑前提供网页入口。保存时明确展示币种、条件和生效状态，保存失败不显示成功。

桌面通知展示股票、规则名称、触发值及触发时间。点击打开对应股票或触发详情。支持全部提醒、仅持仓、选定分组，及声音和免打扰设置。

以服务端事件 ID 去重，启动时不把全部历史未读重发成系统通知。网页和桌面共享已读状态；待处理事项不因打开通知自动完成。

服务端继续负责扫描和规则判定。Mac 应用完全退出或设备休眠时不能承诺实时显示本机通知；恢复后补齐站内记录，并使用现有服务端通知渠道作为补充。

### 5. AI 与组合诊断（第二至第三优先级）

股票详情默认读取已有分析。按钮区分“查看最新报告”与“重新分析”；重新分析需显示任务进度、生成时间和失败重试入口，不随行情刷新反复调用模型。

组合页复用集中度、市场分布、收益贡献和已有风险提示。先展示少量可解释的结论，点击进入网页诊断全文。

快捷问题：“这只股票最新报告关注了什么？”“哪些持仓贡献了今天的盈亏？”“本账户持仓是否过于集中？”只有具备相应数据和证据时生成结论；区分行情时间与报告生成时间。

桌面可将选定股票和账户作为助手上下文传入；会话跳转与上下文传递需适配现有网页路由。分析结果与事实数据分开呈现。

### 6. 策略与机会（第三优先级）

提供“我的关注中出现的新信号”“持仓相关策略变化”“已保存策略计划”的摘要入口。复用机会页、左侧策略快照与报告，显示信号日期、生成时间及数据是否过期。

初期只读查看与网页跳转。完整策略参数编辑、全市场扫描、回测、人工审核与模拟交易保留在网页版，通过具体记录链接定位。

策略信号不能作为实时行情或已成交记录展示。若展示模拟交易数据，明确标注模拟账户，并与真实持仓汇总隔离。

### 7. 登录、连接及设置（第一优先级）

保存最近成功连接的服务地址与用户名；提供可选“保持登录”，令牌存入 macOS 钥匙串，不保存明文密码。过期后重新登录。

连接前识别 PanWatch 服务；将端口不匹配、服务未启动、账号错误、登录过期区分提示。自动重连采用退避，旧数据保留并标明更新时间。

设置包括：显示金额、红涨绿跌/绿涨红跌、刷新偏好、窗口置顶、开机启动、通知、快捷键、退出登录。隐私模式覆盖主窗口、迷你窗口及菜单栏；通知正文金额是否隐藏可单独配置。

自动刷新按市场交易状态调整；前台可见的行情优先，后台降低频率。界面刷新频率与数据源实际更新频率分别标识。

## 网页与桌面的共用边界

| 能力 | 现有基础 | 桌面新增内容 |
|---|---|---|
| 持仓账户与行情 | 账户汇总、关注列表、批量报价、市场状态 | 多账户合并视图、列设置、迷你窗口 |
| 分组 | 现有账户分组 | 跨端关注分组及多组成员关系 |
| 价格提醒 | 规则、命中、冷却和次数限制 | 快速设置、系统通知、事件去重 |
| 通知中心 | 未读、待处理、已读、目标记录 | 原生展示、点击定位、恢复后同步 |
| 分析与助手 | 历史报告、对话及任务状态 | 股票上下文入口、摘要与任务状态展示 |
| 组合诊断 | 集中度、分布、基准和收益贡献 | 精简卡片与风险入口 |
| 策略与机会 | 机会、策略快照、计划、报告 | 关联持仓/关注的摘要和网页定位 |
| 图表 | K 线摘要及部分日线数据能力 | 日线展示适配；分钟级分时需补充数据链路 |
| 桌面体验 | 现有 Dock 窗口 | 菜单栏、全局快捷键、置顶、钥匙串 |

网页版和桌面操作使用同一份业务记录；窗口尺寸、列宽、迷你模式等设备偏好本地保存。网页链接使用普通业务标识定位，不把登录令牌放在 URL 中；网页未登录时先登录再返回目标记录。

## 建议交付顺序

### V0.2：让盯盘主流程完整

共享关注分组、账户筛选与合并、表格排序和列配置、股票详情、已有报告入口、日线小走势、保持登录及重连、隐私模式、迷你置顶。

验收：网页版分组变更可在桌面看到；同一股票多账户数量和成本正确；筛选后总览同步；断网不会把旧行情显示为最新；退出重开可按用户选择恢复登录；金额隐藏覆盖所有桌面展示区域。

### V0.3：让提醒与处理形成闭环

快速设提醒、通知中心、macOS 通知、菜单栏、全局快捷键、分析任务进度。

验收：桌面创建提醒可在网页看到；同一事件仅通知一次；点击通知定位具体股票或记录；拒绝系统通知权限时站内记录仍可查看；休眠恢复不轰炸历史通知；应用退出后的能力范围清晰。

### V0.4：接入研究与策略摘要

组合诊断卡片、持仓关联策略信号、助手上下文、分钟级分时图（数据接入满足后）。

验收：报告和信号显示各自时间；可定位网页原文；行情刷新不触发重复 AI 任务；图表数据缺失时不生成模拟曲线；模拟账户与真实持仓不混算。

## 使用示例

上班时通过菜单栏查看置顶股票 → 收到已有价格规则的命中通知 → 点击展开股票详情 → 查看各账户仓位与最新报告 → 调整提醒条件或进入网页继续研究。

此方案的重点是让持仓、行情、提醒、分析和网页记录衔接起来；每期完成一条可验证的日常使用路径。
