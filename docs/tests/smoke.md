# PanWatch 人工验收清单

本文是跨功能的人工 smoke 基线，不替代具体需求的验收条件。每项记录 `PASS` / `FAIL` / `未执行`、版本、环境、实际操作和证据；自动化测试通过不代表下列真实外部集成已经验收。

## 前置条件

- Python 3.10+；Node.js 24.14.0；pnpm 9.15.9。
- 可访问的 AI 供应商或本地 Ollama；需要验证行情和通知时，准备对应的测试凭证。
- 将 `.env.example` 复制为 `.env`，只使用可丢弃的测试凭据；`.env` 不进入版本库。
- 默认端口：后端 `:8000`，前端开发服务器 `:5183`。

## 自动化基线

```bash
make setup-backend
pnpm --dir frontend install --frozen-lockfile
make check
make test
pnpm --dir frontend exec vitest run
make verify
make doctor
```

`make doctor` 需要可用的数据库和配置；未配置的外部服务应显示失败或跳过，而不是伪造成功。

## 手动验收步骤

### 1. 启动与首次登录

1. 运行 `make dev-api`，确认后端在 `:8000` 启动且无未处理异常。
2. 另开终端运行 `make dev-web`，打开 `http://localhost:5183`。
3. 创建登录凭证，重新登录，确认未登录访问受保护接口被拒绝。
4. 打开引导中心，确认必做步骤不能跳过、暂停后可恢复。

预期：页面可加载，认证生效，引导进度在刷新或服务重启后保留。

### 2. 组合与纸面交易

1. 创建一个测试账户，添加持仓，确认成本、市值、盈亏和币种展示正确。
2. 编辑和删除持仓，确认刷新后数据一致。
3. 打开纸面交易，创建或查看模拟仓位，确认权益曲线和绩效数据随交易更新。
4. 切换账户和页面，确认不会串数据。

预期：数据持久化，计算结果与输入一致，删除和并发操作有明确反馈。

### 3. 行情、K 线与技术指标

1. 分别搜索 A 股、港股和美股标的，确认代码规范化与市场识别正确。
2. 打开详情页，检查报价、K 线、MACD/RSI/KDJ、新闻和资金流展示。
3. 在非交易时段和不同浏览器时区下检查时间戳与交易日状态。
4. 关闭网络或使用不可用数据源，确认页面显示失败状态而不是旧数据冒充新数据。

预期：多市场可用，时区规则符合 [时区策略](../timezones.zh-CN.md)，失败可见。

### 4. 价格提醒与通知

1. 创建单条件和 AND/OR 组合条件提醒，设置冷却、每日限额和过期时间。
2. 使用测试通道发送一次通知；真实送达必须使用明确授权的接收端。
3. 验证非交易日、“全天”模式、过期和限额边界。
4. 检查运行记录和通知历史，确认失败可见。

预期：条件按规则触发，限额和过期生效，模拟发送与真实送达分别记录。

### 5. AI 研究与机会

1. 在设置中配置 AI 服务和默认模型，测试连接。
2. 从持仓或标的触发一次分析，确认使用用户选择的模型并可追溯结果。
3. 打开机会列表，检查排序、入场位、目标和风险上下文。
4. 模型不可用或返回异常时，确认错误反馈和运行记录，不显示伪造结果。

预期：真实模型调用成功时结果可追溯；未调用真实模型时不得登记为 AI 功能整体通过。

### 6. 导航级助手与 Agent

1. 打开 `/assistant`，发送普通查询，确认流式事件和任务状态更新。
2. 触发需要审批的写入工具，分别验证批准、拒绝和取消；确认拒绝后不产生副作用。
3. 刷新页面或重启服务，确认任务快照和恢复行为符合预期。
4. 在 Agent 页面触发盘前/盘中/收盘流程，检查运行历史、失败状态和交易日过滤。

预期：工具审批生效，事件与持久化一致，失败不会被展示为成功。

### 7. TradingAgents 深度分析

1. 从持仓触发深度分析，观察分析师、辩论、风险审查和最终决策链。
2. 确认结果在应用内可追溯，并按配置发送到授权通知渠道。
3. 记录所选模型、耗时、费用相关信息和失败重试行为。

预期：全过程可追溯；模型或外部依赖不可用时如实记录未执行或失败。

### 8. PWA 与移动端

1. 在手机浏览器打开应用并安装为 PWA。
2. 检查主要页面在 390 px 宽度下的布局、滚动、亮色/深色主题和键盘交互。
3. 确认离线或网络恢复时的提示符合预期。

预期：移动端可操作，无裁切、横向溢出或不可访问控件。

### 9. Docker 与镜像产物

```bash
make build VERSION=<test-version>
docker run --rm -p 8000:8000 -v panwatch_test_data:/app/data \
  sunxiao0721/panwatch:<test-version>
docker run --rm -v "$PWD:/checks:ro" sunxiao0721/panwatch:<test-version> \
  python /checks/scripts/docker_smoke.py
```

预期：镜像可启动，首次登录可用，`docker_smoke.py` 的 PDF、截图和 HTTP 启动检查通过。构建和运行需要 Docker、网络和 Playwright 浏览器依赖。
