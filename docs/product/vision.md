# PanWatch 产品目标

状态：active  
负责人：项目维护者  
更新时间：2026-11-11

## 目标用户

- 希望数据掌握在自己手中的个人投资者，使用 Docker 或其他方式自托管。
- 同时关注 A 股、港股和美股，需要在一个工作区管理多账户、持仓和自选标的。
- 希望用自选或本地模型获得 AI 研究、定时盘前/盘中/盘后分析和通知，而不依赖托管式投顾服务。

## 要解决的问题

个人投资者通常需要在行情软件、表格、新闻和聊天工具之间切换：持仓与盈亏分散、价格提醒规则简单、AI 分析结果难以追溯、通知渠道不统一。PanWatch 把这些工作收敛到一个可自托管的 Web 应用和 PWA 中。

## 产品目标

1. **统一组合视图**：多账户、持仓、盈亏、历史与纸面交易表现集中展示。
2. **可配置的市场监控**：行情、K 线、技术指标、新闻、资金流与多条件价格提醒。
3. **可追溯的 AI 研究**：从持仓或候选标的触发分析，保留证据、辩论、风险审查和最终决策链。
4. **按交易日运行的自动化**：盘前展望、盘中监控、收盘报告和深度研究按交易所日历执行。
5. **可控的外部触达**：通过用户配置的通知渠道送达报告和提醒，并支持冷却、限额和过期规则。
6. **自托管与移动可用**：单容器部署、本地数据目录、可安装 PWA，使用用户自己的 AI 与数据源凭证。

## 范围

当前产品包含：

- 组合与多账户、持仓与盈亏、纸面交易。
- A 股、港股、美股行情、K 线、技术指标、新闻、发现与机会列表。
- 多条件价格提醒与通知渠道（Telegram、企业微信、钉钉、飞书、Bark、Webhook）。
- 导航级助手、定时 Agent 和 TradingAgents 多 Agent 深度分析。
- 设置、数据源、AI 服务、模型、日志、健康检查与升级检查。
- 报告与 PDF 导出、PWA 移动端。

## 明确边界

- 交易相关能力当前是**纸面交易模拟**，不替用户向券商下真实订单。
- AI 输出是研究资料，不保证收益；模型、行情和通知供应商的可用性与费用由用户自行选择和承担。
- 不托管用户数据；部署者负责自己的网络暴露、认证凭证、备份和访问控制。
- ETF 深度分析使用基金专用上下文，不等于公司财务报表；基金持仓、净值、费用和跟踪误差尚不作为结构化数据提供。
- 未发布交易日历时，自动 Agent 执行会被阻止；年度日历需要随发布更新。

## 成功标准

- 新用户能按 README 用 Docker 启动，创建登录凭证并完成首次 AI 分析。
- 组合、行情、提醒、Agent、通知和 PWA 的核心路径可按 [人工验收清单](../tests/smoke.md) 复现。
- Agent 运行结果、分析证据和通知记录可追溯，失败状态不会被展示为成功。
- 用户可替换 AI 供应商、模型、行情源和通知渠道，不修改业务代码。
- 代码边界、测试和文档能支持外部贡献者独立完成一个聚焦改动。
